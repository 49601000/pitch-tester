# PitchPad

VOICEVOXの再生成前に、ピッチの方向感を耳で確認するためのローカルツールです。

元音声を毎回生成し直さずに、「語尾を少し上げる」「この単語だけ下げる」「採用候補は何Hzくらいか」といったメモをブラウザ上で作れます。

## 概要

PitchPadは、500Hzから600Hzまでの仮ピッチ音を鳴らして、VOICEVOXのイントネーション調整用メモを作るための単一HTMLツールです。

音声ファイルを読み込む場合も、ファイルは外部送信されません。ブラウザ内だけで扱います。

## 主な機能

- 500Hzから600Hzまでのピッチ音を10Hz刻みで再生
- 音の長さを0.15秒、0.25秒、0.40秒から選択
- 採用中のピッチ値を `pitch: 570Hz` のような形式でコピー
- wav、mp3、m4a、oggなどの元音声を読み込み、聞きながら比較
- 語尾、単語、採用Hzなどの耳メモを記録してコピー
- iPhoneの「ホーム画面に追加」用アイコンに対応

## 使い方

1. `Tool4-pitchpad.html` をブラウザで開きます。
2. 仮ピッチパッドのHzボタンを押して、確認したい高さの音を鳴らします。
3. 必要に応じて音の長さを切り替えます。
4. 採用したい値が決まったら「採用値をコピー」を押します。
5. 「耳メモ」に調整内容を書き、VOICEVOX再生成時の指示に使います。

## 読み込みモード

上部の「読み込み」を押すと、元音声の読み込みパネルが表示されます。

音声ファイルを選ぶと、元音声を再生しながら別系統で仮ピッチ音を鳴らせます。元音声と仮ピッチを聞き比べて、再生成時の調整方針を決める用途に向いています。

## iPhoneのホーム画面に追加する

`apple-touch-icon-ptester.png` は、iPhone用のホーム画面アイコンとして設定されています。

Safariで `Tool4-pitchpad.html` を開き、共有メニューから「ホーム画面に追加」を選ぶと、PitchPadのアイコン付きショートカットとして使えます。

## 注意

PitchPadはVOICEVOXのイントネーションを完全再現するツールではありません。

あくまで再生成前にピッチの方向感を仮確認し、調整メモを作るための補助ツールです。
